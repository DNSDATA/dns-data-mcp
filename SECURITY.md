# Security

DNS-DATA provides authenticated access to devices explicitly linked to an account.

For a suspected vulnerability, please contact the team privately through
https://dns-data.com/ rather than posting exploit details, account data, or
credentials in a public GitHub issue.

**Never submit** passwords, tokens, pairing codes, device IDs, SSH keys, user
data, terminal transcripts containing secrets, or private logs to this repo.

The public endpoint is https://mcp.dns-data.com/mcp. The service may require
OAuth authorization, device binding, and an active account entitlement before
tools can be used.

# DNS-DATA Remote｜中文接入教程

[产品介绍](../README.zh-CN.md) · [English setup](SETUP.md) · [免费套餐每月额度](../README.zh-CN.md#免费套餐每月调用额度)

使用 DNS-DATA，把支持远程 MCP 的 AI 软件连接到**你已经授权的电脑**。这是一项远程 MCP 服务，不需要用户自行部署 MCP 服务器。

## 准备工作

- 注册一个 [DNS-DATA 账号](https://dns-data.com/)。
- 目标电脑：**Windows x64** 或 **macOS Apple Silicon (ARM64)**。
- 目标电脑可以联网，并已安装 Node.js **18 或更高版本**（用于运行官方 npm 启动器）。
- 你使用的 AI 客户端支持 **Streamable HTTP / Remote MCP**，且能完成 OAuth 登录。

免费套餐支持 1 台已绑定设备、**每月 10,000 次 MCP 工具调用**；**次月自动恢复额度**（每月 1 日 00:00 UTC，北京时间 08:00）。

## 步骤 1：在目标电脑启动 DNS-DATA

Windows：打开 PowerShell。macOS：打开“终端”，执行：

```bash
npx -y @dns-data/remote@0.2.1
```

首次运行按照网页或启动器提示注册／登录账号、检查设备信息、核对 8 位验证码，并确认设备绑定。只有你主动完成授权的电脑才能作为目标设备使用。

启动器显示设备在线后，请保持窗口打开。关闭窗口会使设备下线。

> 此命令是**目标设备端的启动器**，不是你要在 AI 中填写的 MCP 地址。通常不需要开放路由器端口或为电脑配置公网 IP。

## 步骤 2：在 AI 软件中添加远程 MCP

在支持此能力的 AI 客户端的 MCP / 连接器设置中填写：

| 设置 | 填写内容 |
| --- | --- |
| 服务名称 | `DNS-DATA` |
| 服务地址 | `https://mcp.dns-data.com/mcp` |
| 传输方式 | Streamable HTTP（如果客户端要求选择） |
| 认证方式 | OAuth（如果客户端要求选择） |

在弹出的 DNS-DATA 页面登录**同一个账号**，确认授权。客户端若支持 OAuth Dynamic Client Registration (DCR)，可以使用自动注册。

ChatGPT、Claude、Gemini、本地 AI 等产品的入口、可用功能和版本要求各不相同。这里的配置只适用于**实际支持远程 MCP 的客户端**；如果软件仅支持本地 stdio MCP，请参考该客户端文档，不能直接套用远程地址。

## 步骤 3：先进行只读测试

对 AI 说：

> 使用 DNS-DATA 列出已绑定的电脑及其在线状态，不要修改文件。

当看到目标电脑在线时，再尝试：

> 在我选定的电脑上查看系统基本信息，不要进行任何修改。

之后可根据设备权限进行文件读取、脚本运行或其他实际任务；写入、删除、服务控制等操作需确认风险。

## 遇到问题怎么办？

**已经添加 MCP，但设备离线：** 检查目标电脑上的启动窗口是否保持运行、是否正确绑定到同一个 DNS-DATA 账号、设备是否联网。

**AI 软件找不到远程 MCP 功能：** 检查 AI 软件版本、语言或账户功能是否提供 Remote MCP / HTTP 连接方式，不能仅凭名称假设兼容。

**提示设备数量已满：** 免费套餐支持 1 台设备，请在用户控制台检查并解绑不再使用的设备。

**提示没有剩余调用额度：** 免费套餐当月额度用完后，次月自动恢复额度（每月 1 日 00:00 UTC），无需重复注册账号。

**OAuth 已授权却无法操作：** AI 客户端获得访问令牌不代表目标电脑已经在线。还要确认启动器、设备绑定、权益和具体工具权限均可用。

**仍然无法解决：** 前往 [DNS-DATA 联系我们](https://dns-data.com/zh/contact/) 或 [GitHub Issues](https://github.com/DNSDATA/dns-data-mcp/issues) 反馈。不要公开密码、令牌、验证码、SSH 私钥或包含私人数据的日志。

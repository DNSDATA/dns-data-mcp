# DNS-DATA Remote MCP：可复现使用案例

[中文产品介绍](../README.zh-CN.md) · [English examples](USE-CASES.md) · [中文接入教程](SETUP.zh-CN.md)

以下案例展示如何通过支持远程 MCP 的 AI 软件使用 DNS-DATA。所有操作均限定在**已绑定、已授权、在线**的电脑上，具体操作能力取决于设备端权限与所使用的 AI 客户端。

## 1. 验证电脑是否连接

> 使用 DNS-DATA 列出我账号下已绑定的电脑及其在线状态。先不要修改任何内容。

如果 AI 已完成 OAuth 授权，却没有看到在线电脑，请先在目标电脑启动 DNS-DATA 服务。

## 2. 检查 Windows 开发电脑

> 选择我指定的 Windows 电脑，查看操作系统信息、正在运行的进程和服务状态。不要停止、启动或修改任何服务。

适用于分析开发环境和进程异常。

## 3. 让 AI 了解本地项目

> 在选定的电脑上，查看我指定项目目录的文件列表、README 和开发文档，解释项目结构与启动方法。不要读取或输出密钥、密码及客户数据。

应明确限定目录，避免无关文件被读取。

## 4. 经过确认后执行构建

> 先检查代码并提出构建与测试命令，说明每条命令可能产生的影响。**在得到我确认之前，不要运行命令或修改文件。**

建议先在测试电脑上操作，不要直接修改正式生产环境。

## 5. 比较两台电脑

> 列出我的在线设备。等我选择 Windows 电脑和 Mac 后，分别查看两台电脑的基本系统信息，并作对比，不要更改设置。

免费套餐支持绑定 1 台设备，初次使用建议先检查这台设备的状态。

## 6. 检查故障服务

> 在我指定的设备上，检查服务状态与相关进程，分析可能的故障原因，并提出恢复方案。没有我的明确确认，不要重启、禁用或删除服务。

需要高权限的操作取决于目标设备端的授权配置。

## 免费套餐月度额度如何恢复？

免费套餐支持 **1 台设备、每月 10,000 次 DNS-DATA MCP 工具调用**，**次月自动恢复额度**（每月 1 日 00:00 UTC，北京时间 08:00）。这里的次数不是 AI 模型对话次数，也不包含 AI 平台消息或 Token 额度。

[免费额度说明](../README.zh-CN.md#免费套餐每月调用额度) · [中文接入教程](SETUP.zh-CN.md) · [GitHub 问题反馈](https://github.com/DNSDATA/dns-data-mcp/issues)

**安全提醒：** 仅操作自己拥有或获准管理的电脑。高风险命令先审核再执行；不要公开口令、令牌或私人日志。
